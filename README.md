# Arrêt Auto — Mises à jour

Ce dépôt public sert uniquement de canal de distribution pour l'application
**Arrêt Auto** (utilitaire Windows de programmation d'arrêt automatique).

Il ne contient **pas de code source** — celui-ci est développé dans un dépôt
privé séparé. Seules les [Releases](../../releases) de ce dépôt sont
utilisées :

- l'installateur Windows (`setup_arret_auto.exe`),
- une somme de contrôle SHA256 associée (`.sha256`),
- les notes de version.

L'application vérifie automatiquement ici (API GitHub publique, lecture
seule) si une version plus récente que celle installée est disponible.
